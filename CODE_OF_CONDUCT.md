# Code of conduct

Draft. The maintainer has not adopted this text yet.

## Expected behavior

Be respectful. Critique the drawing, the code, and the decision. Assume
other people are here to build panels that are safe to wire.

## Unacceptable behavior

- Harassment, slurs, or sexual attention that is not wanted
- Publishing someone else's customer drawings, photos, or contact details
- Posting API keys, webhooks, or tokens
- Asking a contributor to ignore the license or a security report

## Where it applies

Issues, pull requests, and any chat the project later names as a community
channel.

## Enforcement

The maintainer may remove comments, block accounts, and reject changes.
Until a public maintainer contact is listed, enforcement is whoever holds
the copyright in `LICENSE`.
